# 分组、项目与窗口栏

分组对应 Space，项目对应 terminal 标签。`useTabs` 仍是所有标签及活动标签的事实来源；收纳只改变导航入口，不关闭后台命令行，也不影响手机的完整项目列表。

## 顶部项目

`GroupSwitcher` 在同一菜单内管理分组与项目，点击分组向下展开，再点收起，不切换二级页面，也没有“进入此分组”。展开同时激活分组，可在空分组新建项目；多个分组可分别展开，关闭菜单保留展开状态。项目列表支持选择、重命名和关闭，显示目录及 agent 状态。选择项目同时切换空间及活动标签，菜单关闭不把焦点抢回分组按钮；展开分组不抢走菜单焦点。中文输入确认不提交重命名，Enter 与 blur 不重复提交。

顶部显示所有分组有 agent 进程的项目，点击时切换到该项目所属分组。图标使用所属分组名称的第一个 Unicode 字符，分组重命名即更新；角标保留运行、待处理及完成提示。检测复用 OSC 驱动的 agent store 和项目面板到 PTY 的映射，分屏中任一面板运行 agent 即常驻；等待输入、完成后空闲仍保留，进程退出才收纳。冷标签不当成运行项目。筛选只订阅 agent 名称字典，不因每次 working/attention 变化重新筛选。拖动间隙映射回完整标签列表，支持跨分组项目排序，但绝不改变 spaceId 或 ownerTabId，隐藏文件不会改变拖动目标。

## 底部窗口

原侧栏“窗口”移至底部左侧，替换路径及其他左侧状态信息。第一项固定返回当前项目终端，其他项是该项目打开的文件、Markdown、网页预览和 Git 页面。选择和关闭使用独立按钮，未保存文件有标记；顶部 Windows 环境按钮已移除，已有分组的环境与 WSL 后端保留，语言服务仍可在设置中管理。

窗口按 `spaceId` 和 `ownerTabId` 双重过滤，未归属窗口单独存放，不能混入某个项目。标签 ID 单调增加，按 ID 排列即打开顺序，不受顶部项目拖动影响。文件栏单击默认持久打开不同文件，不替换旧预览；显式预览入口仍可复用当前项目自己的预览槽。同路径去重、Markdown 视图转换、Git diff、历史及提交文件复用均核对所属项目，不会激活其他项目的窗口。关闭活动文件优先选择同项目其他窗口，最后一个关闭后返回所属终端。底栏选择还检查当前作用域，拒绝旧项目残留事件。

文件树“打开/打开中”与窗口栏复用 `scopedWindowTabs` 的范围。由同一纯函数提取编辑器、Markdown、Git diff 和提交文件的磁盘路径；仅当前范围的活动文件标为“打开中”。当前项目全部窗口关闭后，即使其他项目仍打开相同路径，也不显示“打开”；绝对路径不重复拼接仓库根目录，Windows 路径身份仍统一大小写与分隔符。

`ResizeObserver` 测量左侧实际宽度，固定项目项 112px、窗口项 128px、间隔 4px，由此计算容量，至少保留一个窗口。不再固定限制 10 个文件。放不下时关闭最早打开的已保存窗口，优先保留后打开的；活动、最新和未保存窗口不自动关闭，受保护项超出容量时可横向滚动。隐藏的零宽度不触发关闭，切换项目重建测量，卸载释放观察器。

真正关闭前，App 核对当前项目作用域，`useTabs.closeTab` 再在同步更新内核对最新标签归属、活动 ID、最新窗口及 dirty，拒绝过期关闭请求，不依赖 App 上一帧的标签镜像。只有成功关闭后才清除编辑器/预览句柄。自动关闭走与常规关闭相同的标签释放入口，不关闭终端。窗口缩窄可能减少已保存窗口，再次打开文件即可恢复；未保存内容不会为了适配宽度丢弃。横向滚动区域自动显示活动窗口，没有活动文件时显示最新窗口，不让受保护的旧文件遮住新窗口。右侧用量和按钮在窄窗口中可换行，不挤到窗口栏上。

## 最近项目与 agent 自动恢复

活动终端以及文件所属项目记录 `lastUsedAt`，随现有空间状态持久化。启动按时间跨分组选取最近 5 个非私密项目，恢复项目终端；其余项目保留冷标签，不自动启动。旧数据没有时间字段时，优先上次活动项目，再按既有顺序选取。窗口和分屏结构仍保存，文件标签按需加载。

保存 `lastAgentSession` 包含 Claude/Codex、明确的会话 UUID 和目录，不保存自由文本启动命令。运行中的 agent 启动后约 1 秒检查一次，随后每 15 秒检查最近项目的活动面板，退出保存也检查；没有对应 agent 时周期检查不读历史。复用后端现有有界目录扫描、头部缓存和每个 PTY 的运行身份绑定，不读取整段对话，也不以目录最新文件猜会话。尚未建立唯一绑定时不保存可恢复身份。私密项目不保存，旧版本没有保存身份的项目需在升级后先运行一次会话。

快照写入串行，不同定时/失焦/关闭请求不交错。明确会话存入现有工作区 JSON，新字段有类型、大小及 UUID 校验，旧格式仍可加载。空闲后保留最后成功捕获的会话，关闭项目移除运行期缓存。

启动只恢复选中项目上次活动面板的 agent，不自动新建对话或重放消息。后端先核对会话存在、ID 和 cwd 归属，WSL 历史不借用 Windows 记录。前端等待真实 shell 附着和 OSC 就绪，隐藏终端先绑定已有渲染器读取提示符；等待期间保护该槽，不抢焦点，不使用 xterm 私有接口。已关闭/换面板、用户开始输入、已有任务、目录变化、启动或提示符超时均停止恢复并提示，不发未确认命令。StrictMode 和重新渲染只尝试一次。恢复 5 个真实 CLI 会增加相应后台进程，属于用户要求的行为，不保证无资源开销。

## 验证边界

临时仓库外脚本直接加载实际组件和纯函数，检查分组/项目隔离、agent 筛选、跨分组拖动、展开收起、重命名 IME、文件复用与标识、宽度驱逐及自动关闭保护。恢复验证包含最近五项、私密排除、新旧持久化、非法 UUID、隐藏渲染器就绪以及输入/目录/旧范围/超时保护。独立 Edge 用生产 CSS 检查 1280/800/420px 底栏布局、C/O 同行及完整可见，周边服务按钮使用替身，未启动真实 Claude/Codex 或覆盖用户运行中的应用。仓库不保留这些验证脚本及测试依赖。
