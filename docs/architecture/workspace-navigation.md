# 分组、项目与窗口栏

分组对应 Space，项目对应 terminal 标签。`useTabs` 仍是所有标签及活动标签的事实来源；收纳只改变导航入口，不关闭后台命令行，也不影响手机的完整项目列表。

## 顶部项目

`GroupSwitcher` 首层管理分组，点击分组进入其二级项目列表。列表支持选择、重命名和关闭，显示目录及 agent 状态；可返回首层，也可进入空分组后新建项目。选择项目同时切换空间及活动标签，菜单关闭不把焦点抢回分组按钮。中文输入确认不提交重命名，Enter 与 blur 不重复提交。

顶部只显示当前分组有 agent 进程的项目。检测复用 OSC 驱动的 agent store 和项目面板到 PTY 的映射，分屏中任一面板运行 agent 即常驻；等待输入、完成后空闲仍保留，进程退出才收纳。冷标签不当成运行项目。只订阅 agent 名称字典，不因每次 working/attention 变化重新筛选。拖动间隙映射回该空间完整标签列表，隐藏文件不会改变拖动目标。

## 底部窗口

原侧栏“窗口”移至底部左侧，替换路径及其他左侧状态信息。第一项固定返回当前项目终端，其他项是该项目打开的文件、Markdown、网页预览和 Git 页面。选择和关闭使用独立按钮，未保存文件有标记；环境选择移到顶部分组旁，语言服务仍可在设置中管理。

窗口按 `spaceId` 和 `ownerTabId` 双重过滤，未归属窗口单独存放，不能混入某个项目。标签 ID 单调增加，按 ID 排列即打开顺序，不受顶部项目拖动影响；已有工作区恢复及文件预览替换语义保持。

`ResizeObserver` 测量左侧实际宽度，固定项目项 112px、窗口项 128px、间隔 4px，由此计算容量，至少保留一个窗口。不再固定限制 10 个文件。放不下时关闭最早打开的已保存窗口，优先保留后打开的；活动、最新和未保存窗口不自动关闭，受保护项超出容量时可横向滚动。隐藏的零宽度不触发关闭，切换项目重建测量，卸载释放观察器。

真正关闭前，App 核对当前项目作用域，`useTabs.closeTab` 再在同步更新内核对最新标签归属、活动 ID、最新窗口及 dirty，拒绝过期关闭请求，不依赖 App 上一帧的标签镜像。只有成功关闭后才清除编辑器/预览句柄。自动关闭走与常规关闭相同的标签释放入口，不关闭终端。窗口缩窄可能减少已保存窗口，再次打开文件即可恢复；未保存内容不会为了适配宽度丢弃。横向滚动区域自动显示活动窗口，没有活动文件时显示最新窗口，不让受保护的旧文件遮住新窗口。右侧用量和按钮在窄窗口中可换行，不挤到窗口栏上。

## 验证边界

临时仓库外脚本直接加载实际组件和纯函数，检查分组/项目隔离、agent 筛选、拖动间隙、二级菜单、重命名 IME、宽度测量、自动关闭保护及清理。独立 Edge 用生产 CSS 检查 1280/800/420px 底栏布局，周边服务按钮使用替身，未启动真实 Claude/Codex 或覆盖用户运行中的应用。仓库不保留这些验证脚本及测试依赖。
