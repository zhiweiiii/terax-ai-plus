## 仓库 HEAD 与分支列表刷新（2026-10-10）

扫描只负责仓库发现，不能作为长期不变的当前分支来源。多仓库层使用 useRepoStatuses 的最新 HEAD 元信息供菜单显示，活动仓库来自 summary，其他仓库来自同环境状态；没有工作区变更的仓库也更新分支名及 detached 标记，不额外扫描。变更文件列表仍过滤干净仓库。

分支 checkout 成功后重新查询该仓库分支列表。读取按仓库持有独立请求身份，强制刷新取代切换前旧读取，成功/失败/loading 清理都仅由当前请求处理；普通菜单 hover/focus 保留去重，旧环境/卸载结果仍拒绝。仓库外实际模块隔离验证不操作用户 Git 数据。

分支操作后的状态摘要 refresh 同样使用 force，绕过切换前在途请求的合并，调用已有 doRefresh 生成新代次；默认刷新不改变原合并策略，旧请求 finally 不能清除新句柄。

## 提交历史搜索和文件列表边界

历史筛选栏接通此前缺失的文本输入，明确搜索当前已加载提交；清空搜索后继续加载更早历史。普通文本本地筛选，正则在独立模块 Worker 中执行，仅需要时启动，80ms 防抖，1 秒超时后终止并提示简化表达式。过滤与高亮使用同一组匹配区间，界面线程不再运行用户正则；查询、提交集合或大小写变化及卸载时终止旧 Worker，旧结果按身份拒绝。无结果及非法表达式都有反馈，未新增依赖。

提交文件列表缓存涵盖加载、成功和失败条目，最多 16 项及 8 MiB 字符/对象估算，最多四个并发请求；超出单项容量明确报错，不静默截断文件。丢弃更老缓存不修改仓库文件，失败项仍可重试。通用 useAsyncQuery 的同步抛错转成失败状态，调用前再次核对请求代次，作废查询不触发原生读取。

## 目录监听注册与设置写入

每条注册保存规范路径、调用者显示路径及环境。通知按非递归目录根索引映射原路径，WSL UNC 不作为 Linux UI 路径直接发送，junction 别名不丢失；Windows 根键规范大小写，WSL UNC 后缀保留大小写。事件带 workspace，编辑器、目录树及 Git 只处理所属环境；目录树按规范身份定位已加载节点。最多 8192 个注册路径且路径存储 8 MiB，每批原生及别名通知总计最多 4096 个路径和 8 MiB，溢出向注册环境发 rescan，不默默漏更新。后备 mtime 轮询保留，已删除描述旧精确字符串比较的重复注释。

`fs_watch_add` 返回注册句柄，前端释放时等待注册完成并只调用一次 `fs_watch_remove({lease})`。后端保存本次实际成功注册的规范路径，释放不再查询磁盘，所以删除、改名或 junction 重定向不会遗留引用。共享目录仍按引用计数取消监听。规范化和注册/释放在 blocking 池运行；单请求最多 4096 个路径、每路径 32768 字节、总 1 MiB，最多 4096 个注册批次及 8192 个目录的保守上限。监听不可用时保持现有文件重读降级行为。

偏好保存和通知在单窗口共用队列；保存失败向调用者返回错误，队列继续接受后续请求。LSP activation 和语言格式化覆盖规则的读取、修改、保存位于同一队列内，不使用滞后的 React 副本覆盖其他规则。这不是跨窗口或外部进程事务锁。设置页直接引用 ThemeProvider，避开主题编辑/空间恢复导出层，不加载不需要的终端运行图。

## 标签状态与设置边界

文件、历史、预览和私密终端图标不订阅 agent 状态，仅普通终端图标监听，避免其他标签因 agent 活动更新重绘。块耗时按进位后的整数单位格式化，不显示 60 秒或 60 分的尾数。标签拖动同步间隙、捕获释放及卸载恢复原 userSelect，块完整元信息变化和耗时进位均已隔离验证。

标签计划在同步引用上计算，React 状态只接收完成的结果；分屏分配和终端释放不依赖 React 更新器的执行时机，连续打开不丢失先前标签，owner 不跨空间继承。Windows 盘符/UNC 路径规范分隔符和大小写，Linux 路径保留大小写；历史文件标签包含空间身份。旧无人使用的空间概览已删除，当前 GroupSwitcher 保留。

设置控件观察保存失败并显示反馈，自启更改排除并发且旧状态读取不能覆盖新更改。手机密码提交绑定挂载及请求代次，保存期间禁止编辑，长度与原生要求一致。终端块覆盖层仅在可见内容变化时更新，比较完整块元信息而非只比较位置；块搜索关闭或卸载清理高亮并尊重输入归属。标签拖动释放 pointer capture 并恢复原 userSelect。

提交面板按环境、上下文、仓库和分支隔离。暂存、提交、丢弃、改写及预览/差异读取共用同步门闩，原生命令前后检查所属范围；失败的丢弃确认保留，多仓库选中和文件路径包含所属仓库。预检查失败阻止提交，预览失败不直接推送，拉取只允许快进。反馈只在推送实际成功时显示已推送，错误不自动消失。

## 终端输入归属与诊断

签名更新将下载与安装分开，Windows 插件安装可能直接退出应用，不能依赖窗口关闭事件保存。主窗口在下载完成后等待工作区保存并检查未保存文件及前台终端任务，阻止不安全安装。设置窗口通过主窗口事件重新检查并展示确认，不自行安装。更新请求去重、按挂载代次拒绝旧结果并释放 Update 句柄；存储节流不可用不影响更新检查，自动失败不阻塞启动。

`terminalInputOwner` 只返回 shell 提示符输入栏、xterm 或无输入。正常退出禁用输入，异常退出保留 xterm 的回车重启入口。运行中的 TUI 不由输出回调反复移动焦点。

`syncLeafInput` 统一同步公开 `disableStdin` 与 textarea 的 disabled 状态；仅在需要且 textarea 确实持有焦点时 blur。槽位创建仍有初始设置，绑定后按会话策略同步。启动、重启和退出同样遵循策略。

blocks 的 prompt 经过前台任务检查，检查绑定 `promptEpoch`。新命令 C 标记、重启、退出使旧代次失效；晚到的“没有前台任务”不能覆盖新命令。xterm 光标和 composition view 保持原生，不使用私有补丁或定时强制刷新。

主窗口开发者控制台可调用：

```js
window.__teraxTerminalDiagnostics.enable()
window.__teraxTerminalDiagnostics.snapshot()
window.__teraxTerminalDiagnostics.disable()
```

默认关闭，无定时器、落盘或输出正文采集。开启后最多记录 256 个事件：PTY 字节数、公开光标坐标、render 行范围、尺寸、可见性、焦点、composition start/end。snapshot 同时返回已有资源统计，disable 清空记录。该入口供可打开开发者工具的环境使用，不是用户界面遥测开关。

排障看同一 leaf 的 output、parsed、render 是否连续，以及 mode/focus 是否意外切换，用来区分数据停止、解析停止和绘制停止，不能替代 Windows IME/Codex 真机复核。

## 会话绑定与缓存

PowerShell 在命令启动前发出带时间的内部 C 标记，恢复命令 UUID 一并记录。Claude/Codex 文件必须核对 cwd，Claude 的有损目录名不是身份凭据。

明确恢复 ID 按 ID 找文件。新会话只选择启动后创建的唯一匹配文件，固定到本次 agent 退出。读取结束再次核对运行代次，IO 期间换 agent 不推送旧快照。多个候选、没有 cwd、交互式 picker 恢复旧文件而命令中无 ID，继续使用屏幕视图，不按最新 mtime 猜测。唯一新文件仍是保守发现机制，不是 CLI 提供的进程身份接口。

历史目录索引最多 32 项，扫描有效期 2 秒；头部缓存最多 512 项，每次读最多 192 KB。菜单不开不扫描，绑定成功后不再扫描历史目录。

每种 JSONL 读取器共享最多 8 个文件缓存，以文件偏移增量读取。状态未变直接返回缓存 Arc。未结束的行和分段 UTF-8 不提前消费；长度缩短、创建时间变化、同长度重写重置解析。针对追加日志，不检测保持文件状态不变的任意原地篡改。

最多保留最近 600 个原始消息步骤，再合并助手轮次；旧工具索引随裁剪调整。单条记录上限约 16 MiB，超大记录跳过；工具结果仍裁剪至 10 行/800 字节。缓存限制按文件数/步骤数，不是严格总字节内存限额。首次加载仍扫描文件，以后只读新增内容。

JSONL revision 是进程内单调代次，不是时间戳，同时间工具结果也推送。发送身份包括 agent、session ID、revision；退出或来源不可读发送 transcriptClear。opencode 保留 SQLite/WAL 指纹路径。

Claude 用户记录兼容带或不带 origin 的格式；工具结果、isMeta、压缩摘要不当作用户发言。

## 手机提交确认

非空输入使用 `{submit:{id,text,leafId}}`，校验请求编号、64 KB 上限及附着目标，writer flush 后返回 writeAck。Codex 使用 bracketed paste 再回车，其他程序普通文本再回车。

确认只表示写入 PTY，不表示 agent 已读取、接受或执行成功。确认前禁用发送按钮，仍可编辑输入；成功只清空仍等于已发送内容且仍在同一终端的草稿。

失败、断线或 15 秒超时保留内容，不自动重发。未确认内容在同一终端重试复用编号，同一 PTY 缓存最近 128 个结果，失败也缓存以避免部分写入后重复执行。不保证跨 PTY 重启、浏览器刷新或缓存淘汰的 exactly-once。结果未知先检查终端，避免改内容重发造成重复。空回车及控制键仍走原始输入。

## 编辑器与后台进程复核（2026-10-02）

文档读写使用文件代次与读取修订号；dirty 状态同步写入 ref，晚到的重载不会覆盖用户输入。保存按请求顺序串行执行，包括撤销到旧基线时的再次保存；切换文件后不再回写旧视图或应用格式化结果。保存前和原子替换前核对 mtime，错误保留 dirty 状态。外部进程仍可能在最后检查后写入，mtime 机制不是严格跨进程事务。

文件读取在实际读取中限制 10/50 MB。新建文件使用独占创建；复制拒绝目录自包含和递归文件链接。原子保存保留权限并跟随目标文件链接，不把链接替换为普通文件。

一次性 shell、Git 与 LSP 使用 Job Object，超时或退出先终止后代再等待输出线程。Git 输入与输出并行，避免大输入写满管道。LSP 头部最多 16 KiB，部分启动失败清理子进程；关闭时先终止进程再锁 stdin。

Claude/Codex 用量探针同样持有 Job Object，收到结果或超时后终止进程树再等待管道。LSP transport 在 spawn 尚未返回时关闭，会在收到 session ID 后立即杀掉该会话。用量缓存与查询参数不变，不额外发起付费查询。

LSP 启动前收到的服务器请求，应答排队到 session ID 可用后发送；关闭或退出清空待发送与接收队列，晚到消息被忽略。配置请求校验 items 数组，非法参数返回 JSON-RPC 错误，不抛出回调异常。

每个 preset 的启动代次在禁用和重启时失效。异步检测、根定位、spawn 与扩展附着都校验当前启用状态和代次。并发容量包含已建立、启动中和关闭中的会话；关闭完成后通知文档重新获取容量。旧实例的退出事件必须匹配 transport 身份，不能按相同 key 关闭新实例。底层库将初始化异常转为已完成 Promise，因此另检查 client.ready，初始化失败按退出清理和退避，不误报运行中。

CI 的 Rust 检查先安装手机构建依赖。打包指纹包含原生资源、配置与手机配置，文件名按 NUL 分隔，二进制按原始字节计算。`v<version>` 标签必须匹配清单，不自动加版本号。尚未验证实际 GitHub runner 发布和签名安装。

## 侧栏交互与持久化

打开文件列表的选择和关闭必须是并列按钮，不能嵌套交互元素；键盘聚焦显示关闭按钮，dirty 编辑器显示未保存状态。侧栏折叠时只标记窗口视图。侧栏宽度限 220-480，只有有效用户拖动才安排保存；卸载先写入仍在等待的最新宽度。原生 DragDropEvent 的 PhysicalPosition 按 DPR 转为逻辑坐标，内部拖动不重复转换。

## 清理与验证范围

工作区存储写入串行化，关闭前显式保存空间列表、活动空间和全部空间的标签，再等待磁盘保存。空空间保存空列表，已删除空间不从旧快照复活；写入失败不更新去重缓存，下次可以重试。保存失败保留窗口，关闭检查等待期间再次核对未保存文件，前台进程探测失败按忙碌处理。

项目删除也检查未保存文件与前台进程，检查期间标签发生变化同样要求确认；取消作废旧请求，最后一个空间不可删除。项目名称输入忽略输入法组词回车，提交和失焦共用一次性门闩，避免新建两份。终端标签关闭检查使用最新面板树，新增分屏不会被旧空闲结果直接关闭。路径事件归一化 Windows 分隔符，并同步更新 Markdown 标签。

终端启动前输入队列超限返回失败，不再报告成功。shell 输入栏只有提交被接受才清空草稿；此确认表示已排队或发起写入，不保证 shell 命令执行成功。异步 PTY 写入、关闭和初始尺寸操作捕获异常，尺寸回复只应用到相同 PTY 的最新请求。隐藏网格在前台检查未完成时保持忙碌保护，失败也不作为空闲回收。

恢复前检查空间及标签结构、重复 ID、有效枚举和数值，并限制面板树深度及节点数量。损坏数据报错且不启用持久化，避免用默认数据覆盖原始记录。首次启动同样应用配置的 WSL 环境及目录。工作区切换使用请求代次，等待目录及授权后再次检查 dirty，只有最后一次请求可以同步清理与重置；晚到的目录回复不能覆盖新的空间。

系统打开文件事件在恢复前排队，恢复后再处理；监听只注册一次并读取最新回调，避免切换目录时漏事件。预览搜索快捷键按标签 ID 定位 iframe，不使用终端 leaf ID。

设置加载与两个通知来源共用 settings/validation.ts，校验类型、枚举、有限数值及结构化记录。偏好初始化先订阅后读取，缓冲读取期间的更新；加载或监听失败清理订阅并允许重试。校验不在读取时重写用户磁盘配置。字体自动选择不能只依赖 fonts.check，另与通用字体基线比较宽度，避免选中不存在的 Nerd Font。

Git 内容捕获超限直接报错，不能拿半个文件做 diff。仓库路径检查不改变操作对象，最终文件链接只验证父目录，工作区正文读取仍拒绝链接；远程名称在创建及推送时拒绝选项前缀。

Git 提交文件状态和 numstat 分别读取，避免 Git 的 name-status 模式覆盖统计输出；两次查询均固定提交 SHA，并按第一父提交处理合并、包含根提交和重命名。输出超限返回错误而不显示残缺列表。多仓库解析与 fetch 最多 4 个工作线程，目录发现预算按实际访问的目录计数，WSL 子路径随递归逐层累积。提交预检查通过绝对 git-dir 定位进行中的 merge/rebase。

已移除无调用的历史 reword/fixup/squash/drop/create-patch API、注册与专属临时脚本。普通提交 amend、已接线的指定提交 amend、撤销和挑选提交不在删除范围。

指定提交 amend 先检查 Git 2.32 及目标的祖先关系，按完整 SHA 而非可能重复的标题定位；空消息保留原提交全文，根提交使用 root rebase。合并提交或跨合并的历史在修改前拒绝，避免自动扁平化历史。amend 标记机制对应 [Git 2.32 commit 文档](https://git-scm.com/docs/git-commit/2.32.0)，失败可能保留 Git 的 rebase 冲突状态，应用不会擅自 abort 或重置用户改动。

删除确认无调用的直接依赖、notification 原生插件/权限、Linux clipboard capability、旧分块和非 Windows 包配置。字体仍由 CSS 使用，Tauri CLI 由脚本动态调用，LSP shim 被 Vite alias 引用，不能按误报删除。

`pnpm knip --include 'files,dependencies,unlisted,unresolved'` 做结构检查。默认完整 Knip 仍报告现有公共 barrel/内部帮助函数 exports/types，不等同于业务实现无人使用。包装脚本禁用 raw transfer，避免 Windows 本机大 ArrayBuffer 分配失败。

仓库不保留测试用例。通过 lint、TypeScript、Rust clippy、前端构建及临时运行模拟验证；模拟覆盖竞态和缓存边界，不能宣称已经证明真实设备光标稳定。

Markdown 预览与编辑器共用绑定空间环境的文档读取，监听及轮询包含两类标签。搜索用 Range/CSS Highlights，避免拆改 React 管理的节点；每个预览独立持有并清理范围。项目文件链接解码后交给受授权约束的文件打开流程，未知 scheme 不导航应用，页内片段限定当前预览。

差异缓存使用环境/仓库/类型/模式或 SHA/路径/重命名前路径的 JSON 元组键，6 项及 8 MiB 文本估算双预算。缓存失效删除在途登记；完成回调只有仍拥有该登记才回填或移除，避免旧请求污染刷新结果。GitDiffPane 固定空间环境，并在 effect 前屏蔽旧身份内容。暂存和历史差异不写工作区，未暂存块回滚先核对完整磁盘基线并携带 mtime 写入，写入失败刷新；不把只读视图的程序化 dispatch 当作自动安全检查。

文件重命名与删除通知使用实际执行环境，只处理同环境空间的对应文件标签。切换期间已成功的磁盘操作仍通知原标签，而旧目录请求不回填新项目。

目录继承和最后聚焦终端按空间及环境保存，文件 owner 必须在同空间，优先读取活动 pane 的 cwd；没有终端时使用本空间历史或根目录，WSL 不拿 Windows home 作兜底。空间删除或环境变化清理旧记忆，context 通知基于语义范围而非标签对象身份。UNC 面包屑保留 server/share 根及扩展路径前缀转换，Windows home 匹配忽略大小写，POSIX 保持区分。子目录下拉复用有环境/请求代次保护的异步查询，过期结果不能回填，失败可重试；触发器为键盘可操作按钮。

生成 UI 不手工打补丁。src/components/FindBox.tsx 在消费者外层处理 IME 和匹配缩减后的索引；ProjectMarkdownCode 保留完整语言、隔离旧高亮状态并对大型代码块降级。预览仅在搜索打开时启用 DOM 变动观察，合并到单个动画帧重新搜索，清理时取消，不是终端刷新补丁。

网页预览地址统一解析并限制 HTTP/HTTPS、8192 字符，无控制字符或嵌入凭据；拒绝应用当前 origin 及 tauri.localhost/asset.localhost 内部页面。地址栏、系统浏览器按钮及实际 iframe 共用规则，恢复记录不能绕过。主/设置入口在 frame 中拒绝启动，避免预览重定向到应用后再次清理 PTY。iframe 保留现有开发页面所需脚本/存储 sandbox 权限，这些检查不等同于对任意开发服务器内容的完整安全隔离。端口探测可取消，草稿输入、地址更新、后续请求和卸载拒绝旧回复；900ms 超时明确反馈而不保留检查中状态。地址栏输入法确认不导航。

命令面板最近使用记录限制原始长度、条数和有限整数时间戳，损坏记录不参与排序；主题预览在关闭、卸载及过滤掉当前主题时清除，IME 确认不执行命令。设置窗口显示不依赖隐藏窗口中可能暂停的动画帧。

全局快捷键匹配和设置录制器忽略组合输入及 229 事件，录制按键去重并移除未使用的修饰键状态。工作区分组在设置中显示；编辑器原生撤销/重做只读，不允许保存不会生效的覆盖。快捷键修改与清除按钮可键盘操作，存储错误可见。

主题设置先订阅后读取，读取期间按字段代次保留新选择；自定义列表按请求代次拒绝乱序及卸载后的回复，存储和监听失败可见。自定义主题验证结构、重复 ID 和 256 项上限，单窗口修改串行化；不同窗口同时执行读改写仍非事务。自定义 ID 与内置 ID 重合时选择器显示一项并使用自定义值。主题文件固定 Windows 本地环境并验证文件名 ID，重新编辑不覆盖磁盘已有文件。主题写入事件携带原工作区，读取不用当前环境；异步编辑跨空间切换后不打开错误项目。WSL 空间暂不直接编辑 Windows 主题文件，明确提示切到本地。

背景图按图片 ID 隔离挂载，切换及卸载释放对象 URL 和动画帧；IndexedDB 事务中止有失败返回，版本变更关闭连接，阻塞后晚到的打开结果也关闭。主题文件导入限制 1 MiB，导入/删除及背景导入/删除各有同步门闩，失败不隐式切换当前主题。主题卡片的选择、编辑和删除使用并列原生按钮，键盘聚焦时显示操作。

图标关联表线性构建为无原型字典，文件名、扩展名和目录名归一为小写，语言 ID 保持其原始定义。语言表及 Iconify 数据只接受自有属性，避免特殊文件名访问对象原型。具体名称优先于复合扩展名，扩展名由最长后缀逐级回退，后声明关联覆盖先声明关联。

Git 历史远程地址按带协议 URL 与 SCP 两类解析，仅支持公开 GitHub/GitLab/Bitbucket host，GitLab 保留完整分组层级。分支查询绑定仓库及环境并按请求代次应用，不复用旧范围结果。文件历史日志及 patch 查询显式携带原环境，折叠/关闭/卸载使在途回复失效。提交确认操作排除并发，成功后关闭刷新、失败保留；仓库/提交/环境改变重新挂载确认状态，卸载或旧环境不执行操作。提交图限定六条轨道的视觉范围，溢出用计数说明，不覆盖正文。

WSL 刷新共用在途请求且失败可重试。Web 状态查询失败与明确未运行分别显示，不从未知状态推断服务停止。

历史主面板按仓库/环境隔离挂载；刷新、卸载和初始查询递增请求代次，文件缓存完成及清理都核对原代次。分页允许错误状态重试，当前筛选的 since 固定在初始加载时间，不随翻页漂移；无新增 SHA 时停止分页。图缓存只对同模式且原输入确实是前缀时增量追加，第一父提交切换重新计算。

供应商面板按 leaf 隔离状态，变更与探针共用门闩。切换/停用先查询前台任务，拒绝忙碌或查询失败，使用当前 cwd 重启，失败恢复原 pin。切换包含一次明确说明的探针，失败不改变全局选择；卸载后的探针不能继续重启。保存取最新全局配置，跨窗口读改写没有严格事务保证。用量查询仅在用户操作时触发、共用门闩，晚到初始化缓存不覆盖新查询。

标签切换同步更新临时状态，快速松开修饰键也能提交，关闭的候选拒绝提交。切换 HUD 跟随选中项并提供辅助技术播报，新标签菜单展示用户实际绑定。终端键盘规则只保留 Windows，alternate buffer 不转换成 readline 导航。

终端 CSS 颜色探针一次性创建固定 21 个隐藏子节点，后续读取不交错写样式与读取计算结果；颜色仍由 CSS 实时计算，不缓存旧主题值。无引用的旧动画/隐藏类整段删除，保留实际使用的动效和 xterm 原生 slider。

LSP 二进制检测缓存只接受当前请求，旧调用跟随最新检测；失败记录独立于缺失，刷新清除错误且可重试。运行字典无原型，提示选择当前路径所属的最长根，不引用其他项目会话。格式化对完整回复校验后一次应用，文档或插件变化、卸载、变为只读时不应用；跳转同时核对请求与可见编辑器，隐藏旧标签不抢焦点。启用写入和自定义列表变更各自单窗口串行，自定义服务器重试保留提交 ID。设置跨窗口读改写不是严格事务。

useLspExtension 的加载结果携带渲染身份，路径、语言、ready、activation、preset ID 或服务 generation 改变立即返回 null，不等 passive effect 清理。晚到句柄同时检查取消标记与当前身份并释放；清理只释放自己取得的句柄，不通过 setState 清空其他范围。新建文件输入有明确名称和错误 alert；操作仍固定根目录与环境，取消后不能撤销已经开始的原生创建，但晚到结果不打开或关闭新对话框。

颜色 Widget 的业务可编辑标志使用 canEdit，不覆盖 CodeMirror WidgetType 的只读 editable 属性。只读状态不生成选色 input，实际写入再次核对文档原色及编辑权限，选色保留原 alpha。Markdown checkbox 同样遵守 readOnly/editable，Ctrl 点击链接仍可打开。定位列表使用每面板独立选项 ID，IME 不确认，空列表可 Escape 关闭。

WSL home IPC 和 Web 密码设置异步进入 blocking 池，避免 WSL 启动/磁盘/Argon2 占用界面线程。PTY 的同步后台初始化直接复用 wsl_home_blocking，发行版先校验，探测仍保持超时及输出预算。

旧 SidebarRail 和非响应式快捷键标签入口已无调用方，整体移除；侧栏视图通过现用工作区布局切换，快捷键显示继续使用响应式 hook。旧远程状态展示、快捷键全量重置、空间头像颜色/首字母、focusedLeafId、serverById、SHIFT_KEY 的无调用逻辑删除。SPACE_COLORS 保留给已有空间记录的校验，不移除兼容数据。静态工具的未外部使用导出中仍有本文件正在调用的内核函数，不能据此删除实现。

项目 Markdown 使用 Streamdown 2.7.0，代码围栏由 ProjectMarkdownCode/ChatCodeBlock 渲染，Mermaid 围栏仍作为可复制代码显示，不启用额外图表插件。依赖包不再包含原 Mermaid/KaTeX 链。Tailwind @source 扫描 dist/*.js，因为入口已拆成转发文件和实现分块。previewRehypePlugins 使用默认 raw 与 sanitize，保留 HTML 和协议白名单；不使用会丢失相对路径的 harden。MarkdownLink 禁止 webview 导航，外链只允许 HTTP/HTTPS/mailto/tel，项目路径拒绝控制字符和其他 scheme，由原目录解析并打开。

分支写操作通过 useRepositoryOperation 固定工作区副本、同步排除重复调用，完成时核对仓库/环境/打开身份及挂载代次；关闭重开同一路径也拒绝旧完成。差异与分支比较采用 useAsyncQuery，范围键包含完整查询及环境，失败保留重试。仓库定位在调用前后核对当前空间，卸载作废请求。这些检查不能撤销已开始的原生 Git 操作。

批量推送返回所有 failed 与可强制重试的 rejected 子集；只有 failed 为空才关闭确认。单仓库 force-with-lease 重试合并剩余失败，普通失败要求重新审阅计划，防止重复推送已成功仓库。当前仅支持 tracking remote，UI 不提供无实现的目标选择。分支选择器按仓库集合/环境重建缓存，多个列表请求各自显示加载/失败；写操作统一门闩，执行前重新校验当前分支及原环境，保护确认失败不关闭。
