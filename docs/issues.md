# 限制与近期变更

这里只保留仍有效的限制、待验收事项和近期重要结论。详细设计见 [文档索引](README.md)，旧修复过程与逐文件审查记录从 Git 历史查阅，版本说明以 [GitHub Releases](https://github.com/zhiweiiii/terax-ai-plus/releases) 为准。

## 当前限制

- 平台只有 Windows；LSP、本机历史读取、自动会话恢复、CLI 控制凭据和 Claude 本机网关注入不支持 WSL 的全部路径，不用 Windows 记录冒充 WSL 记录。
- 自动恢复最多最近 5 个非私密项目，每项目上次活动面板一个 agent。旧版本没有具体 UUID，升级后先运行会话并成功保存；不恢复私密项目，不自动新建对话。
- Web 使用明文 HTTP/WS，绑定所有网卡，必须在可信局域网/VPN 后使用，不直接暴露公网。
- asset scope 仍为 `**`，不是项目目录沙箱；收紧前需兼顾任意用户选择媒体、背景和 WSL 路径。
- 视频支持取决于 WebView2 实际编码能力，部分 MOV/MKV/AVI/HEVC 不能内嵌播放；失败提示后可手动系统打开。
- 手机选项与状态降级解析有启发式，CLI 界面变化可能影响识别。工具输出是有限预览，超限需桌面查看；过快输出可能断连重新同步，快照接缝可能短暂重复。
- 消息去重限同一 PTY 的有界缓存；跨重启/刷新不保证恰好一次。定时任务结果未知不自动重发，取消不能撤回模型请求；应用未运行或睡眠时不执行。
- 设置/主题跨窗口读改写、外部 Git 和文件进程没有严格事务隔离。mtime 检查不是文件锁，应用门闩不能撤销已开始的原生命令。
- 大文件、复杂差异和历史读取有资源预算，可能降级或明确拒绝，不把部分内容冒充完整内容。Git diff 预算耗尽仍可粗略比较。
- 当前默认手动更新；签名自动安装渠道未完成实际验收。安装提权与日常运行提权不是同一要求。
- 并行启动多个 agent 会增加 CLI 与必要活网格资源，渲染器预算不是全进程内存上限。开发缓存大小不等于安装包或运行占用。

## 验证边界

1.0 代码审查完成过两轮工程检查及关键隔离回归；用户确认测试通过后发布正式版。静态、mock IPC、独立 Edge 和手机尺寸检查，不等同于所有真实设备验证。

改动相关仍需实际确认：Windows Codex/Claude 长时间输出、输入/删除/IME、标签切换与滚动；升级后的真实会话恢复；实际 WSL 附件/文件监听；iOS Safari 键盘与断线；原生覆盖安装、签名更新与真实后台 CLI 定时请求。不得将这些限制写成“已彻底证明稳定”。

## 1.0.4 变更（2026-10-10）

- 顶部项目首字去掉状态点及不必要的阶段订阅，其他运行检测不变。
- 媒体改为独立预览，修复 Windows http asset origin 被 img/media CSP 拦截，以及 SVG 等落入文本编辑器。按所属环境解析路径，失败可见，隐藏音视频暂停。
- Changes 使用完整父目录，单文件也有分组标题，根目录和多仓库分别隔离；缩至单文件后仍能展开，不被旧折叠状态永久隐藏。

代码修改已通过 lint、类型、Rust fmt/clippy、前端构建、资源体积检查及相关仓库外逻辑回归，媒体未在真实 WebView2/WSL 文件上验收。媒体 CSP 修改需重启原生开发进程或安装新包生效。

完整 Windows x64 NSIS 构建成功，程序版本为 1.0.4，安装包为 `Terax_1.0.4_x64-setup.exe`。版本标签与下载见 [v1.0.4](https://github.com/zhiweiiii/terax-ai-plus/releases/tag/v1.0.4)，不包含签名自动更新。
