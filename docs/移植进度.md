## 四、问题与待办

### 🔴 1. native.ts 被误删（重建中）
- 现象：某 agent 误删 `src/modules/ai/lib/native.ts`（含 33 个新命令绑定 + 15 个新类型）
- 处理：基础版已从 git HEAD 恢复；全部新绑定由其他 agent 重建中（消费方调用点已收集：gitCommitAdvanced 等 34 个方法）
- 依赖：全量验证（check-types/lint/vitest）必须等重建完成

### 🔴 2. vite 启动挂起（热部署窗口不显示）
- 现象：vite ready 后 HTTP 不响应（TCP 通、请求超时），窗口 hidden（前端 show() 未执行）
- 已试：watch.ignored 加 rebased（未解决）
- 待查：vite 依赖优化器扫描（optimizeDeps 对 923MB 目录的全量扫描）或 watcher 初始化；候选方案：`optimizeDeps.entries` 收窄、或把 rebased/ 移出项目根

### 🟡 3. 全量验证（待 native.ts）
- `pnpm check-types`：待 native.ts 重建后
- `pnpm biome lint`：历史上 source-control 14 条既有 warning、git-history 若干（非新增）
- `pnpm test`：source-control 34/34、git-history 96/96（rebased 排除前数据）
- `cargo check --lib`：✅ 通过

### 🟡 4. 已知取舍（有意为之）
- 多仓库 Pull 无逐仓库进度列表（顺序循环+聚合 toast）

- 分支选择器固定 h-80，窗口高度 <380px 时可能溢出
- 二级菜单滚动时锚点不随动（radix 无滚动监听，hover 场景可接受）

### 🟢 5. 已完成清理
- PullStrategyDialog、RepoSelector、nativeGit.ts 已删除
- 日志菜单 reword/fixup/squash/drop/patch/push-up-to 已移除
