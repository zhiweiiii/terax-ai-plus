# Porting history (archived)

These documents record the Git/IDEA VCS porting batch from mid-August 2026.

They are **historical records only**. They reference code that has since been
removed (the AI subsystem, the test suite, `src/modules/ai/`, `rebased/`, and
the macOS/Linux platform branches). Do not treat their claims as current
architecture; `TERAX.md`, `docs/architecture/`, and `docs/issues.md` are the
current truth.

- `porting-issues.md` - issue log from the porting batch
- `移植进度.md` - porting progress notes (Git/IDEA VCS port)
- `idea-vcs-porting-checklist.md` - detailed porting checklist for the Git/IDEA VCS features
