# Terax 1.0.0

Terax 首个 1.0 正式版，支持 Windows x64。

## 本次发布

- 终端使用 xterm 原生输入、光标和显示路径，优化 PTY 输入排队、阻塞 IO 与进程回收。
- 手机端优化窄屏布局、实时对话、发送确认、断线重试及长内容资源限制，支持 Codex 和 Claude Code。
- 合并 Codex / Claude Code 会话历史，按项目隔离；支持用量查询及持久化多任务定时消息。
- 完善编辑器、文件监听、差异比较、Git 操作、LSP、工作区切换与设置的异步边界和失败反馈。
- 清理确认无用的代码，升级 Markdown 渲染依赖并保留安全过滤与项目文件链接。
- 完成代码侧全面审查、两轮全仓工程检查及关键交互回归；用户确认测试通过后发布。

## 安装与更新

下载 `Terax_1.0.0_x64-setup.exe` 并运行。默认安装需要管理员权限；应用运行权限与安装权限分开。覆盖安装前建议保存未保存文件并退出旧应用。

当前使用手动下载安装渠道，没有发布未配置签名的自动更新包。Windows 可能对未签名安装包显示安全提示，请核对下载来源与发布资产 SHA256。

## 已知边界

仅支持 Windows。LSP 暂不支持 WSL 工作区。复杂差异在计算预算耗尽时可能退化为粗略结果。跨窗口设置及外部文件/Git 进程不提供严格事务隔离。代码检查与用户测试通过不代表不存在任何缺陷，审查证据和验收边界见仓库 `docs/release-1.0-audit.md`。
